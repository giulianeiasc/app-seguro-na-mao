# App Seguro na Mão

Projeto de Extensão — **Segurança em Aplicativos** (uso seguro de apps e privacidade de dados).

Site educativo e interativo para ajudar pessoas comuns, principalmente quem tem pouca familiaridade com tecnologia, a reconhecer apps falsos, permissões abusivas e golpes de roubo de conta, e a conhecer seus direitos pela LGPD.

## O que tem no site
- **5 riscos** em aplicativos, com sinais de alerta e como se proteger
- **Caso prático**: pedido de código no WhatsApp
- **Desafio**: "esse aplicativo é confiável?"
- **Quiz** com 5 perguntas e explicações
- **Checklist**: "Antes de instalar um aplicativo..."
- **Infográfico** de resumo
- **Se der problema**: o que fazer após instalar um app suspeito

## Arquivos
- `index.html` — o site completo (HTML, CSS e JavaScript em um único arquivo)
- `Projeto_Extensao_Seguranca_Aplicativos.docx` — documento do projeto

## Tecnologias
HTML, CSS, JavaScript e Google Fonts. Apoio de IA (Claude, da Anthropic) na pesquisa, nos textos e no código.

## Fontes
CERT.br (Cartilha de Segurança para Internet), LGPD (Lei nº 13.709/2018), Idec e Febraban.
